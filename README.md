# Casa dos Gatos Café – Frontend

Projeto acadêmico desenvolvido em **Angular** para a disciplina de Frontend. A aplicação simula o sistema da **Casa dos Gatos Café**, espaço parceiro da Associação Amigos dos Gatos de Foz do Iguaçu.

**Slogan:** *“Café, calma e gatos. Um refúgio no meio da cidade.”*

---

## Objetivo

Desenvolver uma **Single Page Application (SPA)** com navegação por rotas, interfaces administrativas e dados mockados para demonstrar conceitos de frontend moderno.

---

## Funcionalidades previstas

* Página inicial do projeto
* Vitrine de gatos disponíveis
* Área de finais felizes (gatos adotados)
* Formulário de interesse em adoção
* Agendamento de visitas
* Login administrativo
* CRUD de gatos
* CRUD de visitas/agendamentos

---

## Tecnologias

* Angular
* TypeScript
* HTML5
* CSS3
* Figma (prototipação)

---

## Estrutura básica

* `/` – Home
* `/gatos` – Gatos disponíveis
* `/finais-felizes` – Gatos adotados
* `/adocao` – Formulário de adoção
* `/visitas` – Agendamento de visitas
* `/login` – Login administrativo
* `/admin/*` – Área administrativa

---

## Como executar

```bash
npm install
ng serve
```

Acesse: `http://localhost:4200`

---

## Equipe

Projeto desenvolvido em grupo para fins acadêmicos. Cada integrante pode contribuir por meio de commits e pull requests neste repositório.

---

## Observações

Nesta etapa do trabalho, o sistema utiliza **dados mockados** e não possui integração com backend real.
